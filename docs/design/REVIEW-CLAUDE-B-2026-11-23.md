## What is good

- Unknown engines count as cloud (`scope.ts:37`), the safe direction; YAML that does not parse is cloud too.
- Failover never switches after output has started (`failover.ts:96`), and an aborted turn is never retried.
- `attach.ts` is a dry run by default, backs up before editing and uses a marked block for Codex, so removal is exact in the normal case.
- The MCP server is read only and has no write tool.
- The translation prompt tells the model the strings are data, and the answer must be an array of the same length.

## What I did not check

I did not run Hermes one-shot with a slash command, did not try a real cloud failover, did not test the i18n routes as an anonymous caller, and did not read `core/server.ts` beyond the lines named. Severity of the three high rows other than the gateway bypass depends on decisions only Konrad can make (what an attached agent may see, whether a local thread may ever leave the machine).
