# Studio merge map: Off Grid functions and Caesar's 49 tools, merged by what they have in common

Author: claude-b, 2026-11-22. Konrad's rules: Off Grid Desktop is the base for every aspect, we take its solution where we lack one, and where both have the same thing we merge into one better version; our tools that are similar become one studio. The dream behind it: Caesar fully operates the computer and the phone, as Off Grid's computer use does.

## How the overlap was found
I ran it: for each of the 49 Caesar tools, Jev was asked which Off Grid function it overlaps most (29 options, or "none"). 49 calls, USD 0.0023. Where Jev was confident (60 percent or more) I accepted it; where it was weak or wrong I decided myself and say so. Jev got four wrong or doubtful: Praetorium (not health), Mercatus (not updates), Web tools (not knowledge), Reels (not actions).

## The dream: operating the computer and the phone
- Off Grid's computer use is the spec to follow (refs first, macros, checkpoints, no model call for simple waits). Read in `docs/reference/OGAD-COMPUTER-USE-MECHANISM-2026-11-22.md`.
- Today: Hermes' `computer_use` toolset is enabled, so a crew member can already be asked to operate this machine. What is missing is our side: a **steps pane** (what it is doing now), an **approval** before anything outward or irreversible, a **screen preview**, and **Stop everything** wired to it.
- Phone: the phone is a controller first (approve, chat, start a task); operating the phone itself needs the native mobile app and its own plan.
