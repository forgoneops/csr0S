# Docs

- `plan/` the build plan and register. Start with `ATRIUM-PORT-PLAN-2026-11-22.md`.
- `design/` design records: one file per decision, audit or spec, named `TOPIC-YYYY-MM-DD.md`.
- `STATE.md` the running state of the build, newest at the top.

Evidence screenshots are not versioned. Audits link to `design/captures/...`; those folders are produced by the
capture scripts in `tools/` and kept in a local evidence archive, so a fresh clone has the notes without the pictures.
